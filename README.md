# 面试助手Agent（MS-Agent-Lite）· 纯文本版面试材料生成 Agent

> 你好，欢迎使用 MS-Agent-Lite——一个把「简历 + 岗位 JD」变成整套面试准备材料的小工具：只需配置一个文本模型，上传简历、填好 JD，点一次按钮，即可得到一份含 8 个部分的面试准备网页（附内容审核），简历扫描件等图片文字由软件内置的本地离线识别自动处理，全程数据只保存在你本机。使用中如有任何问题或建议，欢迎联系我：[llxstupg@163.com](mailto:llxstupg@163.com)。

> **📌 版本：v0.4.12-Lite（2026-08-08，产品体验优化：横版三栏布局 + 引导/分级/成功路径）**
> **📦 另一版本**：本仓库是 **MS-Agent 纯文本版（Lite）**——只需配置**一个文本模型**即可完整使用，生成的面试材料质量与视觉版相当；无需视觉模型。另有视觉版 **[MS-Agent](https://github.com/LI-PG1/MS-Agent)**：识图走「视觉模型 + 文本模型」或「多模态模型」两种路径。
> **💰 低成本实现**：一个 **DeepSeek-V4-Flash**（`deepseek-v4-flash`）文本模型即可完整使用本版；识图由本地离线识别自动完成，无额外费用。
> **💸 花费参考**：一次完整生成（8 份材料 + 内容审核）约消耗 **15 万 tokens**（输入：简历 / JD / 参考信息，输出：8 份材料正文），按 DeepSeek-V4-flash 官方现价（输入 1 元 / 百万 tokens、输出 2 元 / 百万 tokens）约 **0.2 元**；工作日高峰时段（9:00–12:00、14:00–18:00）价格约翻倍至 0.4 元。识图走本地离线识别，不产生模型费用；数据仅存本机，无其他隐藏成本；DeepSeek 官方已公告近期将上调定价，实际费用以最新官方价格为准。

## ✨ 它能做什么（结果一览）

```
📄 你的简历（pdf / word / txt / md，上传后作为本次权威简历）
📋 岗位 JD（可直接粘贴文本，或链接读取）
🔗 补充参考网址（可选，最多 15 条）
📝 补充参考信息（可选，面经 / 公司背景 / 技术文章 / 发展方向等文字，≤20000 字）
🌐 联网搜索（可选增强，Tavily）：遇时效信息 AI 自动标注【待联网核实】清单；配置搜索 Key 后自动联网核实权威来源
        │
        ▼  点一次「🚀 一键生成面试材料」，自动调用你配置的大模型 API
🎯 【岗位名称】面试准备.html —— 一份可打印、可分享的网页材料，含 8 个部分：
   自我介绍 / 项目深挖 / 技术场景题 / 反问环节 / 面试题库 / 数字口径速查 …
   并附带 LLM 内容审核（对照你的简历，检查数字与项目真实性 → PASS/WARN）
```

- 全程 Web 面板操作：实时进度、失败文件可单独重试、多模型失败自动切换
- 数据留在本地：生成基于你自己的简历与自配 API，明文可查

## 🚀 三步开始（新手上路）

> 详细的长篇图文引导在 `MS-Agent-Lite工程文件\40_界面\使用指南.html`——**下载解压后双击即可打开**（无需安装任何东西）。

1. **下载**（二选一）：
   - **方式 A（安装版，推荐新手）**：右侧 **Releases** 页面下载 `MS-Agent-Lite-v0.4.11-setup.exe`——双击走安装向导（自动创建桌面 / 开始菜单快捷方式），装完从快捷方式启动即可；卸载走系统「应用和功能」。
   - **方式 B（绿色版，免安装）**：点本页右上角绿色 **Code** → **Download ZIP** → 解压到任意目录（如 `D:\MS-Agent-Lite`）。
2. **跟教程**：解压后进入 `MS-Agent-Lite工程文件\40_界面\`，双击《使用指南.html》，它是交互式图文教程（左侧悬浮流程图随步骤点亮，照着走即可）；纯文字备份看 `MS-Agent-Lite工程文件\50_文档\新手安装使用指南.md`
3. **跑起来**：**双击发布包第一层的 `启动面试助手Agent.bat`**——首次启动会自动解压内置的 Node.js 与依赖（约 1~2 分钟，仅一次），随后启动本地服务并打开浏览器 `http://localhost:8900/`（免终端、免安装、免配置环境；之后启动秒开）。无需自行安装 Node.js。手动方式（可选）：

```powershell
cd D:\MS-Agent-Lite\MS-Agent-Lite工程文件\20_执行
npm install      # 首次，自动装依赖
npm start        # 一键启动 → 浏览器打开 http://127.0.0.1:8900
```

页面第 1 步填 API Key → 第 2 步上传简历 + 填 JD → 点「🚀 一键生成面试材料」。

## 四、常见问题

| 问题 | 处理 |
|------|------|
| `npm start` 端口被占用 | 服务已在运行（如之前双击过启动器）——直接访问 http://127.0.0.1:8900 即可；否则关闭占用 8900 的进程后重试 |
| 生成成功但找不到文件 | 生成完成会自动弹窗提示结果文件完整保存路径；也可看页面底部预览窗口，或到 `MS-Agent-Lite工程文件/30_产出/面试材料/<岗位名称>/` 下找「<岗位名称>面试准备.html」 |
| 全部模型配置调用失败 | 打开面板「⚙ 高级设置」，逐个点「配置自检」定位出问题的配置；或到 `MS-Agent-Lite工程文件/20_执行/config.json` 核对各配置的 Key / 接口地址 / 模型名 |
| 简历解析失败 | 确认格式为 pdf/docx/txt/md；PDF 为扫描件/图片型时，系统会自动尝试本地离线识别提取文字（可在设置抽屉查看识别引擎状态），仍失败则请上传文字版 PDF 或另存为 txt |
| 中文乱码 | 终端请用 UTF-8；脚本内部已统一 utf8 读写 |
